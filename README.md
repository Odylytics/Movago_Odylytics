# Movago

> Move smarter. Go safer.

Đề xuất của đội Odylytics cho KTC Ideathon. Movago giúp kế toán công nợ của công ty giao nhận hàng biển kiểm tra từng khoản cước trước khi thanh toán. Hệ thống đối chiếu chứng từ đề nghị chi với hồ sơ lô hàng và giá đã duyệt, rồi đưa ra kết quả kèm căn cứ để người phụ trách xác minh.
